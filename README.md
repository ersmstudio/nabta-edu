# نبتة التعليمية

نبتة منصة تعليمية ثنائية اللغة تجمع مسارات التعلّم في البرمجة والأنيميشن والعلوم. المشروع مبني باستخدام Next.js App Router وReact وTypeScript وPrisma وPostgreSQL. يشمل تسجيل الحسابات، محتوى الدروس والاختبارات، ولوحة إدارة للمحتوى، مع خدمة اختيارية لتشغيل تمارين C# داخل حاويات Docker معزولة.

## ابدأ من هنا

- المساهمون الجدد: [دليل المساهم وبيئة التطوير المحلية](docs/CONTRIBUTOR-GUIDE.md).
- تجهيز الدورات والصفحات: [دليل صفحات الكورسات](docs/COURSE-PAGES.md).
- لوحة الإدارة: [دليل لوحة الإدارة](docs/ADMIN-DASHBOARD.md).
- تشغيل تمارين C#: [دليل مشغّل C#](docs/C-SHARP-RUNNER.md).
- تقديم المشروع للمساهمين: [نص فيديو التعريف](docs/YOUTUBE-INTRO-SCRIPT.md).

## المتطلبات السريعة

- Node.js 20 أو أحدث وnpm.
- PostgreSQL محلي أو قاعدة تطوير منفصلة.
- Docker Desktop عند تجربة تنفيذ تمارين C#.

ابدأ بنسخ `.env.example` إلى `.env` **إذا لم يكن لديك ملف `.env` محليًا بالفعل**، ثم اضبط `DATABASE_URL` و`AUTH_SECRET` و`ADMIN_EMAIL`. بعد تثبيت الحزم، نفّذ `npx prisma generate` و`npx prisma migrate dev`، ثم شغّل `npm run db:seed` و`npm run dev`. الخطوات الكاملة وإعدادات المشغّل الاختيارية في دليل المساهم.

لا تضع مفاتيح أو بيانات اتصال حقيقية في Git. ملفات `.env` مستثناة من المستودع.
