# نبتة التعليمية

نبتة منصة تعليمية ثنائية اللغة تجمع مسارات التعلّم في البرمجة والأنيميشن والعلوم. المشروع مبني باستخدام Next.js App Router وReact وTypeScript وPrisma وPostgreSQL. يشمل تسجيل الحسابات، محتوى الدروس والاختبارات، ولوحة إدارة للمحتوى، مع خدمة اختيارية لتشغيل تمارين C# داخل حاويات Docker معزولة.

الإنتاج الأساسي يعمل على سيرفر البيت T3500 عبر GitHub Actions وself-hosted runner. يستخدم Vercel لمعاينات الفروع والعرض المبدئي، مع قاعدة Prisma Postgres منفصلة للمعاينة؛ لا توجّه بيئة المعاينة إلى قاعدة الإنتاج.

## المتطلبات السريعة

- Node.js 20 أو أحدث وnpm.
- PostgreSQL محلي أو قاعدة تطوير منفصلة.
- Docker Desktop عند تجربة تنفيذ تمارين C#.

ابدأ بنسخ `.env.example` إلى `.env` **إذا لم يكن لديك ملف `.env` محليًا بالفعل**، ثم اضبط قاعدة التطوير المحلية و`AUTH_SECRET` و`ADMIN_EMAIL`. بعد تثبيت الحزم، نفّذ `npx prisma generate` و`npx prisma migrate dev`، ثم شغّل `npm run db:seed` و`npm run dev`. استخدم قيمًا مستقلة لـVercel Preview وقاعدة T3500 الإنتاجية؛ الخطوات الكاملة في دليل المساهم.

لا تضع مفاتيح أو بيانات اتصال حقيقية في Git. ملفات `.env` مستثناة من المستودع.
