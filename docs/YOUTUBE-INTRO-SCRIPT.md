# نص فيديو تقديم نبتة للمساهم

**المدة المقترحة:** 7 إلى 9 دقائق  
**الجمهور:** المساهم الجديد، وأي شخص يريد فهم المنتج قبل المشاركة في بنائه  
**قبل التسجيل:** شغّل نسخة التطوير المحلية، استخدم بيانات تجريبية فقط، وأخفِ البريد ومفاتيح البيئة. لا تعرض `.env` أو أسرار GitHub أو قاعدة الإنتاج.

## 0:00 — ترحيب وفكرة المشروع

**على الشاشة:** الصفحة الرئيسية بالعربية.

**الكلام:**

«أهلًا بيك في نبتة. نبتة منصة تعليمية بنبنيها عشان تساعد المتعلم يكتشف المجال اللي بيحبه ويتعلمه خطوة بخطوة. في الفيديو ده هنعمل جولة في تجربة المستخدم، لوحة الإدارة، وطريقة تشغيل المشروع محليًا عشان نقدر نطوره سوا قبل أي نشر.»

## 0:35 — جولة في الصفحة الرئيسية

**على الشاشة:** العنوان، أقسام الصفحة، المسارات والبحث، زر تغيير اللغة.

**الكلام:**

«دي الصفحة الرئيسية: فيها تعريف سريع بنبتة، ومسارات التعلّم، والبحث عن المجال. الموقع بيدعم العربية والإنجليزية، واتجاه الواجهة بيتغير حسب اللغة. اختيار الموقع الجغرافي اختياري تمامًا؛ المستخدم يقدر يكمل بلغة المتصفح من غير ما يشارك موقعه.»

«المجالات الأساسية اللي بنقدمها هي الأنيميشن والرسم، والبرمجة والتقنية، والطبيعة والعلوم. لما يكون في محتوى منشور في قاعدة البيانات بتظهر المسارات من لوحة الإدارة.»

## 1:30 — الحساب ورحلة التعلّم

**على الشاشة:** صفحة إنشاء حساب تجريبي، تسجيل الدخول، مسار منشور، درس.

**الكلام:**

«المتعلم يقدر ينشئ حسابًا بالبريد وكلمة مرور، وبعدها يفتح الكورسات والدروس المنشورة. صفحة الدرس ممكن تعرض فيديو ووصفًا ونصًا مرافقًا، وبعد الدرس يقدر يجاوب على اختبار. الأسئلة الموضوعية بتتحسب تلقائيًا، أما الإجابة المقالية فبتحتاج مراجعة.»

«وفي دروس البرمجة ممكن نضيف تحدي C#. عند توفر خدمة المشغّل، الكود بيتنفذ في حاوية معزولة وتظهر نتيجة الاختبار للمتعلم.»

## 2:35 — لوحة الإدارة

**على الشاشة:** سجّل ببريد حساب تجريبي موجود في `ADMIN_EMAIL`، افتح `/admin`، اعرض الأقسام دون كشف بيانات أشخاص.

**الكلام:**

«المدير بيدخل لوحة الإدارة من `/admin` بحساب البريد المسموح به في إعدادات البيئة. من هنا نقدر ندير المجالات والكورسات والدروس، نضيف أسئلة وتمارين، نراجع إجابات المقالات والمحاولات، ونحدّث نصوص الصفحة الرئيسية والتذييل.»

«خلّوا المحتوى التجريبي واضحًا إنه تجريبي، وما تنشروش كورس للطلاب قبل مراجعة اللغة والروابط والفيديو والأسئلة.»

## 3:25 — خريطة المشروع

**على الشاشة:** نافذة المحرر على شجرة الملفات، بدون فتح `.env`.

**الكلام:**

«المشروع مبني بـNext.js وReact وTypeScript. مجلد `app` فيه الصفحات وواجهات API. `lib` فيه المصادقة والصلاحيات والاتصال بقاعدة البيانات. مجلد `prisma` فيه شكل قاعدة البيانات وتغييراتها. ومجلد `code-runner` فيه خدمة C# المنفصلة. داخل `docs` هتلاقوا تفاصيل لوحة الإدارة والكورسات ومشغّل الأكواد، بالإضافة لدليل المساهم ده.»

«في فرق بين صفحات الكورسات التعريفية الموجودة مباشرة في الكود، وبين المسارات والدروس اللي بننشرها من لوحة الإدارة. خليك واخد بالك من الفرق ده وإنت بتضيف أو تعدل شاشة.»

## 4:15 — تجهيز Local Dev

**على الشاشة:** اعرض خطوات الدليل، ونافذة طرفية بعد إزالة أي أسرار من الشاشة.

**الكلام:**

«قبل ما نغير أي حاجة، بنجهز بيئة محلية. محتاجين Node.js، وPostgreSQL محلي أو قاعدة مخصصة للتطوير. بعد تثبيت الحزم، بننسخ `.env.example` إلى `.env` لو ما عندناش ملف محلي موجود، ونحط رابط قاعدة التطوير وسر محلي وبريد حساب المدير.»

«بعدها بنجهز Prisma، ونطبق migrations على قاعدة التطوير، ونضيف المحتوى الأولي، ونشغّل الموقع على `localhost:3000`. لو عايزين نجرب تحديات C# كمان، بنشغل Docker ونجهز خدمة المشغّل حسب الخطوات المكتوبة في الدليل.»

**بطاقة على الشاشة:**

```text
npm install
npx prisma generate
npx prisma migrate dev
npm run db:seed
npm run dev
```

## 5:20 — طريقة التعاون بأمان

**على الشاشة:** فرع تطوير أو pull request تجريبي، ثم قائمة مراجعة قصيرة.

**الكلام:**

«شغلنا اليومي هيكون على فرع منفصل، وكل تغيير نراجعه قبل الدمج. مهم جدًا ما نشتغلش على قاعدة الإنتاج وإحنا بنجرّب، وما نرفعش `.env` أو مفاتيح أو بيانات مستخدمين. كمان أي push إلى `main` بيبدأ مسار النشر الحالي، فعشان كده التجربة والمراجعة لازم تحصل قبل الدمج.»

«قبل ما نعتبر المهمة جاهزة، نراجع الواجهة بالعربي والإنجليزي، نجربها على شاشة صغيرة، ونشغّل lint وbuild. ولو ضفنا إعدادًا أو غيّرنا رحلة مستخدم، نحدّث التوثيق.»

## 6:15 — تسليم المهمة للمساهم

**على الشاشة:** افتح دليل المساهم وأظهر قسم خريطة الملفات ومهام البداية.

**الكلام:**

«أول خطوة ليك: شغّل الموقع محليًا واتفرج على الصفحة الرئيسية والتسجيل ولوحة الإدارة. بعدها نختار مع بعض أول مهمة صغيرة وواضحة، نتفق على الشكل المتوقع، ونشتغل عليها في فرع مستقل. لو لقيت حاجة مش واضحة في التجربة أو التوثيق، سجّلها؛ دي جزء من الشغل اللي هنحسنه مع بعض.»

«الرابط الأساسي اللي ترجع له هو `docs/CONTRIBUTOR-GUIDE.md`. شكرًا، ومستنيين نكبر نبتة سوا.»

## بعد التصوير

- راجع الفيديو وتأكد أن أي بريد ظاهر أو بيانات طالب تجريبية لا تكشف بيانات حقيقية.
- أضف رابط الدليل في وصف الفيديو بعد رفعه.
- يمكن إرفاق `docs/CONTRIBUTOR-GUIDE.md` للمساهم مع الفيديو ليستخدمه كمرجع خطوات.
