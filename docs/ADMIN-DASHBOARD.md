# لوحة إدارة نبتة

## فتح اللوحة

أضف بريد حسابك المسجل في الموقع إلى متغير `ADMIN_EMAIL` في `.env`، ثم أعد تشغيل التطبيق وسجّل الخروج والدخول. لا تضف هذا البريد إلى ملفات عامة أو مستودع Git. صفحة الإدارة هي `/admin`.

## ما الذي تديره اللوحة؟

- المجالات وترتيبها وأيقوناتها وثيماتها وظهورها.
- الكورسات وحالات النشر والأوصاف والصور والثيم.
- الدروس والفيديو والنص المكتوب أو المنطوق المرتبط به.
- أسئلة الاختيار الواحد والمتعدد والقائمة المنسدلة والصح والخطأ والإجابة القصيرة والمقالية.
- تمارين C# وحالات الاختبار المخفية، وتسليمات الكود ومحاولات الاختبارات.
- مراجعة درجة الإجابات المقالية من صفحة النتائج.
- نصوص الصفحة الرئيسية وقسم «عن نبتة» والتذييل.

محتوى الطالب متاح من `/paths/{slug}` ثم `/learn/{course-slug}` بعد نشر المجال والكورس والدرس. البيانات العامة لا تحتوي على الإجابات الصحيحة أو حالات اختبار الكود.

## تشغيل C#

الخدمة معزولة وتحتاج Docker؛ اتبع [تعليمات مشغل C#](./C-SHARP-RUNNER.md). بدون الخدمة يمكن إدارة التمارين، لكن زر التحقق يعرض أن المشغل غير مضبوط.
